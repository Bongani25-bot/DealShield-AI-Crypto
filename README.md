## Description
**DealShield AI** is a crypto and market monitoring bot that delivers real-time cryptocurrency updates, market alerts, and VIP signals via Telegram. This repository contains the static website for promoting the bot, allowing users to:

- Subscribe to VIP signals ($5/month) via **PayPal**.
- Access the Telegram bot and group.
- View real-time cryptocurrency prices and bot features.
- Scan a **QR code** to join the Telegram group easily.

The website is lightweight, responsive, and easy to deploy on hosting platforms like **GitHub Pages**, **Netlify**, or **Vercel**.

---

## Features

- **Market Monitoring:** Real-time BTC, ETH, USDT prices integrated with CoinGecko API.
- **Subscription Management:** VIP subscription link via PayPal.
- **Telegram Integration:** Direct bot and group links.
- **QR Code:** Quick access to Telegram group.
- **Responsive Design:** Works seamlessly on desktop and mobile devices.
